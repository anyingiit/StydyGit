## About The Project

StydyGit is a public repository that its owner has archived. Its tree holds only the scratch files someone practicing Git commands leaves behind: `readme.txt`, a plain-text note repeating "Git is a version control system"; `helly.py`, an empty (0-byte) file; `TESTFILE`, a one-line marker; and `test`, a file that still carries an unresolved Git merge-conflict (`<<<<<<<` / `=======` / `>>>>>>>`) from a stashed-changes exercise, exactly the kind of thing this repository was for.

There is no manifest, no entry point, and no source file in any language anywhere in the tree, so there is nothing here to install, build, or run.

See the [open issues](https://github.com/anyingiit/StydyGit/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/), to clone the repository and to reproduce the merge-conflict exercise the scratch files were left mid-way through.
- (Optional) [pre-commit](https://pre-commit.com/), if you want to run the checks declared in `.pre-commit-config.yaml` before committing.

### Installation

```sh
git clone https://github.com/anyingiit/StydyGit.git
cd StydyGit
pre-commit install  # optional -- only needed if you plan to commit changes here
```

## Usage

There is no application in this repository to run. The scratch files are the point: open `test` to see the unresolved merge-conflict markers left over from a stash exercise, or read `readme.txt` for the notes this repository's owner wrote to themselves while learning Git.
